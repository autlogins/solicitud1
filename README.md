# Plataforma de Desembolsos Web

Formulario interactivo para solicitud de desembolsos con validación en tiempo real, gestión de sesiones y control administrativo.

## 🚀 Características

- ✅ Autenticación con documento y contraseña
- ✅ Validación de identidad con fotografías
- ✅ Confirmación por WhatsApp y Email
- ✅ Integración Firebase en tiempo real
- ✅ Panel de control administrativo
- ✅ Notificaciones automáticas
- ✅ Interfaz responsiva (Mobile-first)
- ✅ Animaciones suaves

## 🌐 Deploy

Este sitio está desplegado automáticamente en GitHub Pages:
- **URL Principal:** `https://[usuario].github.io/formulario-desembolsos-web/`

## 📋 Requisitos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Conexión a Internet
- JavaScript habilitado

## 🔧 Configuración

Para usar este formulario en tu propio proyecto:

1. Clona este repositorio
2. Actualiza las credenciales de Firebase en `index.html`
3. Configura tu webhook de Discord si deseas notificaciones
4. Despliega en tu servidor o GitHub Pages

## 📱 Pantallas Incluidas

1. **Login** - Autenticación con documento y contraseña
2. **Monto** - Selección del monto a desembolsar
3. **Cuenta Bancaria** - Selección del método de desembolso
4. **Fotografías** - Captura de identidad
5. **Códigos OTP** - Verificación por WhatsApp
6. **Aprobación** - Confirmación por Email
7. **Éxito** - Confirmación de solicitud recibida
